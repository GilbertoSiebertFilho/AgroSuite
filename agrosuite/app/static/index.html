Save project

A project file (.agrosuite) holds the whole session — every dataset with its cleaning results, roles and prices — and "Open project" brings it back in one step.

A full path, from the drive or the root. Ending in .agrosuite it is the file; anything else is a folder — created if it is not there yet — holding a file named after the project. Left empty, the file is written to the session folder, which goes when the app closes — keep it through the download link that follows.
